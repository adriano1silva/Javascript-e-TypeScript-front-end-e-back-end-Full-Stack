# 📚 Jornada de Estudos - JavaScript e TypeScript Full Stack

Este repositório foi criado para documentar minha evolução durante o curso **JavaScript e TypeScript - Front-end e Back-end (Full Stack)**.

O objetivo é centralizar exercícios, exemplos práticos, anotações, desafios e projetos desenvolvidos ao longo dos estudos, servindo como material de consulta e acompanhamento da minha evolução como desenvolvedor.

---

## 🎯 Objetivo

Consolidar conhecimentos em desenvolvimento Full Stack utilizando JavaScript e TypeScript, aplicando conceitos de Front-end, Back-end, bancos de dados, arquitetura de software e boas práticas de desenvolvimento.
